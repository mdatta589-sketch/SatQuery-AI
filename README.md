# SatQuery-AI
An interactive Vision-Languag# SatQuery AI

Interactive Vision-Language Assistant for
Multimodal Remote Sensing Image Analysis

## Problem

Traditional remote sensing workflows require users to
manually select datasets, bands, models and processing tools.

## Solution

SatQuery AI allows users to interact with satellite imagery
using natural-language queries and combines:

- Remote sensing image processing
- Natural-language interaction
- VQA
- Object grounding
- NDVI analysis
- Geospatial visualization
- Evidence-based results

## Current Prototype

Implemented:

✅ Satellite image visualization
✅ AOI selection
✅ Sentinel-2 imagery
✅ Raster band inspection
✅ NDVI analysis
✅ Natural-language query interface
✅ Remote PaliGemma VQA
✅ GroundingDINO object grounding
✅ Evidence visualization
✅ FastAPI backend
✅ Leaflet-based geospatial interface
